# Дипломный проект профессии «Python-разработчик: расширенный курс»

## Backend-приложение для автоматизации закупок

В рамках выполнения дипломной работы за основу был взят базовый шаблон репозитория Нетологии. В ходе разработки проект был фундаментально переработан, оптимизирован под высокие нагрузки и переведён на современный стек технологий.

---

## 🛠 Выполненные базовые изменения

1. Файловая база данных **SQLite была полностью заменена на промышленную реляционную СУБД PostgreSQL**. Это обеспечило поддержку конкурентных запросов, изоляцию транзакций и масштабируемость системы.
2. Все чувствительные данные, доступы к базам данных, настройки SMTP-серверов и секретные ключи Django были вынесены из кода в **переменные окружения (`.env` файл)**.
3. Модули конфигурации приведены к единой структуре пакета `shop`.

---

## 🚀 Реализованная продвинутая часть (Бизнес-логика)

* **Парсинг и асинхронный импорт**: Написана логика автоматического считывания и обработки прайс-листов от поставщиков в формате **YAML**.
* **Экспорт товаров**: Реализован эндпоинт для выгрузки актуального каталога товаров магазина.
* **Админка заказов и уведомления**: 
  - Разработан механизм управления заказами (смена статусов, сборка, доставка) как через кастомные контроллеры **REST API**.
  - Настроена система мгновенного автоматического уведомления клиентов об изменении статуса их заказов.

---

## ⚡ Оптимизация производительности (Celery & Redis)

Для предотвращения блокировки основного веб-потока все «тяжёлые» и медленные методы были полностью изолированы и вынесены в **асинхронные фоновые задачи**:
* **Отправка писем**: Регистрация, подтверждение токенов и уведомления по заказам отправляются через очереди.
* **Импорт прайс-листов**: Обработка многостраничных YAML-файлов поставщиков выполняется в фоне.
* **Движок**: В качестве брокера сообщений развёрнут **Redis**, а выполнение контролирует **Celery Worker**.

---

## 🧪 Качество кода: Автотесты и ИИ-помощник

Проект прошёл полный цикл контроля качества. Написано **17 комплексных интеграционных автотестов**, покрывающих как B2B-часть (каталог, магазины), так и B2C-сценарии (корзина, адреса доставки, оформление заказов).

* **GigaCode (AI-ассистент)**: Генерация архитектурных шаблонов тестов, сценариев валидации полей и проверок статус-кодов (200, 201, 400, 403) выполнена с помощью искусственного интеллекта в среде **GigaIDE**.
* **Результат**: Тесты полностью стабильны, изолированы и запускаются в автоматическом режиме внутри Docker, возвращая статус **`OK`**.

Команда для запуска тестов в контейнере:
```bash
docker compose exec app python manage.py test
```

## 📦 Инструкция для быстрой сборки и запуска Docker

Вся экосистема проекта разворачивается в автоматическом режиме через Docker Compose.

1. **Клонировать данный git-репозиторий на локальную машину:**
   ```bash
   git clone git@github.com:alexandrtsarkov410/my_diplom.git
   ```
2. **Перейти в корень проекта (директорию с файлом docker-compose.yml):**
   ```bash
   cd My_diplom
   ```
3. **Запустить сборку и старт всех контейнеров в фоновом режиме:**
   ```bash
   docker compose up -d --build
   ```
   *Docker Compose автоматически скачает образы PostgreSQL и Redis, соберёт изолированный образ Django, установит библиотеки из requirements.txt, применит миграции базы данных и запустит воркеров Celery.*
